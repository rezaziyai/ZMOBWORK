# ZMOBWORK

نرم‌افزار مدیریت تعمیرات موبایل برای ویندوز.

## مرحله ۱
- داشبورد مینیمال RTL
- ثبت سریع گوشی
- کد پذیرش ترتیبی از 1000
- برند و پیشنهاد مدل
- نوع مشکل و توضیحات
- رمز گوشی و مبلغ توافقی
- وضعیت‌های در حال تعمیر، تعمیر شده، آماده تحویل و تحویل شده
- چرکنویس سریع
- جستجوی سراسری

## اجرا
```bash
npm install
npm start
```

اطلاعات این نسخه به صورت محلی برای نمونه در localStorage نگهداری می‌شود. دیتابیس امن، همگام‌سازی شبکه دو سیستم، مدل کامل دستگاه‌ها و منطق پیگیری هوشمند در مراحل بعد اضافه می‌شوند.
